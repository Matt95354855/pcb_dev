# Library-backed generation contract (0.2 increment)

This is an implementation contract. It does not grant manufacturing approval.

Bindings JSON: {"schema_version":1,"registry":"registry.json","licenses":["ATTRIBUTION.md"],"components":{"board.part":{"symbol_library":"device","symbol_name":"R","symbol_id":"Device:R","footprint_library":"r0603","unit":1,"no_connect_pins":[]}}}. Licenses are optional contained relative data paths captured with hashes.
registry is a contained relative path resolved within the bindings directory. Existing LibraryRegistry pins source files inside its own directory. Every model component (including DNP) must have exactly one binding. Unknown/missing/extra fields, mutable source hash, unsafe paths and unsupported units must fail before output is written. All symbol pins are either in component.pins or explicit no_connect_pins; footprint numbered electrical pads must cover the symbol exactly. Initial release supports one-unit symbols only (unit0 common + unit1, conversion0/1), top-side placement; any unsupported transformation fails explicitly. No automatic generic fallback.

Core ownership: new bindings.py, sexpr.py, tests/test_bindings.py test_sexpr.py; may extend parity.parse_sexpr with backwards-compatible preserve_quotes option. `sexpr.Quoted(str)` marks quoted atoms, `parse_quoted(text)->list` preserves lexical quotation, `dumps(tree)->str` roundtrips bare enums/numbers vs quoted strings. Default parity parser remains ordinary strings to avoid breaking libraries type checks.

`bindings.load_bindings(design:Design,path:Path)->BoundDesign`. BoundDesign: design:Design, components:dict[str,BoundComponent], provenance:dict (bindings_sha256,registry,registry_sha256,sources:{alias:{file:relative,sha256,kind}},licenses:{relative:{sha256}}), bindings_content:bytes, registry_content:bytes, source_contents:dict[alias,bytes], license_contents:dict[relative,bytes]. BoundComponent: path:str, component:Component, symbol_id:str, footprint_id:str (=component.footprint), symbol_name:str, symbol_tree:list (resolved embedded symbol definition; top name changed to symbol_id), footprint_tree:list (original source AST), symbol_inventory:SymbolInventory, footprint_inventory:FootprintInventory, no_connect_pins:tuple[str,...], unit:int=1. Source data preserved and scoped; flatten local symbol inheritance, reject unsupported multiunit/convert2. Top symbol source name to lib_id and nested symbol names must be KiCad-compatible. No network or arbitrary code.

Backend ownership: backends/library_kicad.py and tests/test_library_generation.py; `generate_bound(bound:BoundDesign,output_dir:Path)->dict[str,Path]` with keys board,schematic,netlist,project,rules,manifest. Embed actual symbol definitions and footprint geometry; stable UUIDs and explicit model nets. Retain actual electrical pin types, real pad/drill/courtyard/silk geometry, stable refs, expected rotations (top only initially). All markers state PCBDEV_LIBRARY_DRAFT, fabrication_ready=false,routed=false, qualified=false. No generic pads or passive pin substitution. Do not modify existing preview generator except exports if needed.

QA ownership: tests/native library smoke module backends/smoke_libraries.py, .github/workflows/native-kicad.yml, examples/library_divider/* and docs/library-generation.md. Use official KiCad library files pinned exact upstream commit+SHA256, preserve CC-BY-SA attribution/license (no false MIT relicensing). Minimize vendored symbol subset while retaining attribution to exact source; no guessed parts. Real connector+two resistors yields schematic and PCB pin-net parity; native ERC may pass but DRC must remain blocked while unrouted. Verify output coordinates/rotation and real pads if native facilities permit.

Root owns pipeline.py/cli.py integration, viewer text, README/roadmap/version/release and PR. Default build remains preview. `build --bindings FILE` produces kind library-draft with copied pinned library sources/provenance, never fabrication approval. Bindings and library sources cannot be located inside output. Root handles complete atomic artifact publication and reproducibility tests.
